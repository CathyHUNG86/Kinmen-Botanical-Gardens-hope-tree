# 金門植物園希望樹

學校教師填寫學生來金門植物園上課後的正向回饋，每收到一則回饋，網站上的樹就長出一片葉子；送出後可打開「希望種子」參加抽獎。

## 檔案

| 路徑 | 用途 |
|---|---|
| `index.html` | 網站本體（樹、表單、抽獎畫面） |
| `images/` | 網站使用的插圖，經 jsDelivr CDN 載入 |
| `apps-script/Code.gs` | Google Apps Script 後端：存回饋到試算表、照片到雲端硬碟、抽獎 |

## 運作方式

- 正式網站是 **Apps Script 部署的網址**。`Code.gs` 會從本儲存庫讀取 `index.html` 顯示給老師。
- 更新 GitHub 上的 `index.html` 後，正式網站約 5 分鐘內自動更新，不需要再改 Apps Script。
- 直接開啟 `index.html`（或 GitHub Pages）只會顯示預覽模式：範例葉子，送出不會儲存。

## 第一次部署

1. 新建一份 Google 試算表 → 擴充功能 → Apps Script。
2. 把 `apps-script/Code.gs` 的內容貼進編輯器，儲存。
3. 函式選單選 `setup` → 執行，並完成授權。會建立「回饋／獎項／設定」分頁與照片資料夾。
4. 在「獎項」分頁填入獎品、數量、機率；在「設定」分頁確認活動期間與抽獎次數。
5. 部署 → 新增部署作業 → 網頁應用程式：執行身分「我」，存取權「所有人」。取得網址後發給老師。

只有修改 `Code.gs` 時，才需要在 Apps Script 重新貼上並「管理部署作業 → 編輯 → 新版本」。

## 規則

- 每位老師（以 Email 辨識）同一堂課最多回饋 2 次；文字與照片不可和自己之前的重複。
- 每位老師抽獎次數依「設定」分頁（預設 1 次）。
- 回饋送出後立即公開（不含姓名與聯絡方式）；試算表「審核狀態」改為「不公開」可隱藏文字。
